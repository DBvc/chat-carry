# ChatCarry 隐私说明草稿

实施完成后必须对照实际代码核实，不能原样当成已审计声明发布。

扩展在用户打开工具栏弹窗后读取当前 ChatGPT 已保存会话，用于本地生成纯文本和 Markdown。读取会使用用户已有 ChatGPT 登录状态，与 chatgpt.com 进行必要通信。扩展不要求单独注册账号。

按本规格，聊天不上传到开发者服务器、第三方分析服务或模型服务；不建立聊天数据库、不做遥测；会话数据只短暂存在于当前运行上下文。凭证仅用于同源读取，不记录、存储或返回到 popup。

用户主动复制后，文字进入系统剪贴板，可能被系统剪贴板历史或用户其他软件访问。用户主动导出后，文件保存到设备下载位置。浏览器还可能保留包含正文的 data URL 下载来源记录。因此不能将本工具描述为“无痕”或“设备上完全不保存数据”。

扩展申请 activeTab、scripting、clipboardWrite、downloads，仅用于当前页读取、纯文本复制与当前导出下载。它不读取其他下载内容、不删除浏览器历史、不读剪贴板内容。

实际维护者联系方式、发布主体与版本日期由项目拥有者在公开发布前补充。没有这些信息时不得把本文冒充已经发布的隐私政策。

当前版本只读取 ChatGPT。路线图平台不预授权、不自动检测登录或采集。以后新增平台需更新实际支持范围及数据使用说明。
