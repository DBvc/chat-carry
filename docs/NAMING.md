# 名称建议与检查边界

检查日期：2026-10-04。推荐工作名 **ChatCarry**，GitHub 仓库名 **chatcarry**。
可放在用户自己的命名空间下，例如 `DBvc/chatcarry`；这只是建议，未创建、预留或确认该账户下的仓库名。

中文副标题：**对话导出**。短句：**把有用的对话带走。**
英文短句：**Carry your AI conversations with you.**
GitHub description：**Minimal, local-first AI chat exporter. ChatGPT first; more platforms next.**

选择理由是产品判断：Chat 表明对象，Carry 表达带走；名称不绑定 GPT、Claude、Markdown 或 Chrome。
它为后续多平台、多格式保留空间，但不是自动导入、会话迁移、跨 AI 续聊功能的承诺。
